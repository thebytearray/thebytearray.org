# The Byte Array Website

This is the official repo of the The Byte Array website, available at https://thebytearray.org.

The site is built with Astro, TypeScript and Tailwind CSS.

## Requirements

Node 22.12 or newer.

## Run locally

    npm install
    npm run dev      # local server with drafts
    npm run build    # production build in dist/
    npm run preview  # serve the production build
    npm run check    # type check

Deployment is described in DEPLOYMENT.md.

## Contributing

Issues and pull requests are welcome. For content changes, the main files are src/data/apps.ts for apps, src/data/policies.ts for privacy policies, src/data/site.ts for site details, and src/content/blog for posts.

## Security

To report a security problem, contact us through https://thebytearray.org/contact/ instead of opening a public issue.
